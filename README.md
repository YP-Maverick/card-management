# Card Management System

REST API для управления банковскими картами с соблюдением стандартов безопасности PCI DSS

- 🔐 Ролевая модель доступа (Администратор/Пользователь)
- 💳 Автоматическая генерация валидных номеров карт (алгоритм Луна)
- 🛡️ Шифрование чувствительных данных (AES-256)
- 🔄 Переводы между картами с проверкой баланса
- 📊 Фильтрация карт по статусу и владельцу
- 📅 Автоматическое отслеживание сроков действия карт
______
## 🔧 Стек технологий

### Основные компоненты
- **Java 17**
- **Spring Boot 3.4.5**
- **Spring Security 6**
- **JWT (jjwt 0.12.3)**

### Работа с данными
- **Spring Data JPA (Hibernate)** 
- **PostgreSQL**

### Безопасность
- **Jasypt 1.9.3** - AES-256 шифрование данных

### Документирование
- **Springdoc OpenAPI 2.8.6** - Swagger-документация
- **Spring REST Docs** - генерация документации через тесты

### Утилиты
- **Lombok** - сокращение boilerplate-кода
- **MapStruct 1.6.0.Beta2** - маппинг DTO

### Тестирование
- **JUnit 5** - модульное тестирование
- **Spring Boot Test** - интеграционные тесты
- **Mockito** - мокирование зависимостей

### Сборка и деплой
- **Docker** - контейнеризация приложения
- **Spring Boot Maven Plugin** - сборка образов

______

### Ключевая функциональность

**Для администраторов**
- CRUD для карт и пользователей
- Блокировка/разблокировка карт

**Для пользователей**
- Переводы между своими картами
- Запросы на блокировку карт
- Просмотр баланса

**Особенности реализации**
- Автоматическое маскирование номеров карт при ответе на запрос 
(**** **** **** 1234)
- Запрет ручного управления защищенными полями Сard
- Инициализация защищенных полей Card EntityListener
- Генерация валидных номеров карт
   BIN банка (6 цифр) - конфигурируется через bank.bin
   Уникальный номер счета (9 цифр) - случайная генерация с проверкой уникальности
   Контрольная цифра - расчет по алгоритму Луна
